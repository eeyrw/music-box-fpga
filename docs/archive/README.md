# Archive

This directory preserves completed migration rationale and merge evidence. The
documents are useful when tracing design decisions, but they do not define the
current implementation. Use [`../design/system_design.md`](../design/system_design.md)
and [`../design/rtl_module_map.md`](../design/rtl_module_map.md) for the current
architecture.

- [`voice_major_renderer_migration_plan.md`](voice_major_renderer_migration_plan.md):
  original frame-major to voice-major replacement plan.
- [`renderer_ddr3_merge_inventory.md`](renderer_ddr3_merge_inventory.md): record
  of the selective renderer/window/DDR3 branch merge.
