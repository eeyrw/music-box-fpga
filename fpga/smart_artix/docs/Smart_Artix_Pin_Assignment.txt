一、系统时钟、复位、按键与板载LED (Clock/Reset/Key/LED)
--------------------------------------------------------------------
信号名称         FPGA引脚    方向      电压标准    描述
CLK_50M          Y18         输入      3.3V        50MHz 系统主时钟
KEY1             E22         输入      3.3V        按键1
KEY2             G22         输入      3.3V        按键2
RESET_N          T20         输入      3.3V        低有效复位按键 (KEY3)
LED1             R17         输出      3.3V        高电平点亮；led_ddr_ready
LED2             P16         输出      3.3V        高电平点亮；led_asset_loaded状态灯

KEY1/KEY2/RESET_N均由10k电阻上拉到3.3V，按下接地，因此低电平有效。
RESET_N另有4.7uF对地电容。LED1/LED2各经330欧姆串联绿色LED到地，
因此FPGA输出高电平时点亮。

当前工程用LED显示无SPI控制链路时的板级启动状态：LED1常亮表示DDR MIG
校准完成；LED2慢闪（亮0.5秒、灭0.5秒）表示SD初始化/加载中，快闪
（亮0.1秒、灭0.1秒）表示SD、恢复或资产加载错误，
常亮表示SD资产已写入DDR，熄灭表示loader空闲。

二、UART 串口接口 (FT2232HL / FT4232HL)
--------------------------------------------------------------------
信号名称         FPGA引脚    方向      电压标准    描述
UART1_TX         R14         输出      3.3V        串口1发送，仅FT4232HL
UART1_RX         P14         输入      3.3V        串口1接收，仅FT4232HL
UART2_TX         P15         输出      3.3V        串口2发送，FT4232HL/FT2232HL
UART2_RX         R16         输入      3.3V        串口2接收，FT4232HL/FT2232HL
UART3_TX         U21         输出      3.3V        串口3 发送 (FT_UART3_TX, 仅FT4232)
UART3_RX         T21         输入      3.3V        串口3 接收 (FT_UART3_RX, 仅FT4232)

板载USB-C下载器使用FT4232HL或FT2232HL。FTDI通道A连接FPGA JTAG
(TCK/TDI/TDO/TMS)，不作为普通用户I/O列入上表。FT4232HL提供3路UART，
FT2232HL提供1路UART；共同可用的一路对应UART2。

EEPROM_SDA       T18         双向      3.3V        I2C 数据

注意：该24C02与第7页FTDI使用的93LC66B/93LC56B配置EEPROM不是同一器件。

六、HDMI 接口 (RX / TX)
--------------------------------------------------------------------
信号名称         FPGA引脚(RX)  FPGA引脚(TX)  接口类型   描述
HDMI_CLK         C18           D17           TMDS差分   时钟通道P端
HDMI_D0          B21           C14           TMDS差分   数据通道0 P端
HDMI_D1          B20           C13           TMDS差分   数据通道1 P端
HDMI_D2          A18           E13           TMDS差分   数据通道2 P端
HDMI_SDA         D15           N14           DDC/I2C    数据
HDMI_SCL         E16           N13           DDC/I2C    时钟
HDMI_HPD         D16           N15           3.3V逻辑   热插拔检测

TMDS负端使用同一Bank16差分对的互补封装脚，详见原理图第2/4页。
HDMI连接器侧有49.9欧姆上拉、ESD器件、5V/DDC电平转换和HPD外围；
不能把TMDS通道按普通LVCMOS33单端GPIO约束。

九、FPGA配置、JTAG与QSPI启动接口
--------------------------------------------------------------------
信号名称         FPGA引脚    方向      描述
FPGA_TMS         T13         输入      板载FTDI JTAG
FPGA_TCK         V12         输入      板载FTDI JTAG时钟
FPGA_TDI         R13         输入      板载FTDI JTAG数据输入
FPGA_TDO         U13         输出      板载FTDI JTAG数据输出
INIT_B           U12         双向      配置初始化状态
PROGRAM_B        N12         输入      低有效配置复位
CFGBVS           U8          输入      配置Bank电压选择
DONE             G11         输出      配置完成；另驱动板载红色LED5
M0               U11         输入      配置模式选择
M1               U10         输入      配置模式选择
M2               U9          输入      配置模式选择；板上选择Master SPI
QSPI_CLK/CCLK    L12         输出      配置Flash时钟
QSPI_CS          R19         输出      W25Q128JV片选
QSPI_DQ0         P22         双向      W25Q128JV IO0/DI
QSPI_DQ1         R22         双向      W25Q128JV IO1/DO
QSPI_DQ2         P21         双向      W25Q128JV IO2/WP_N
QSPI_DQ3         R21         双向      W25Q128JV IO3/HOLD_N

配置Flash为W25Q128JVSIQTR，3.3V、128Mbit (16MiB)。QSPI_CS、DQ2/WP_N
和DQ3/HOLD_N各有4.7k上拉；DQ0和DQ1没有图示外部上拉。配置/JTAG专用脚
由Vivado配置流程管理，不应作为普通顶层GPIO重复约束。
当前Smart Artix XDC将BITSTREAM.CONFIG.SPI_BUSWIDTH设为4；FPGA先以串行
方式读取启动头，再切换到x4配置传输。生成持久镜像时必须使用SPIx4。

十一、板载下载器与电源事实（原理图第7页）
--------------------------------------------------------------------
- USB接口：USB-C，经板载FT4232HL/FT2232HL连接JTAG和UART。
- JTAG：FTDI通道A连接FPGA_TCK、FPGA_TDI、FPGA_TDO、FPGA_TMS。
- FTDI配置EEPROM：93LC66B或93LC56B。
- 主电源输入：5V_DC；板上生成VCC3V3、VCC1V8、VCC1V5和VCC1V0。
- BANK15电源VCCIO_ADJ由可更换SPX3819M5 LDO设定，默认3.3V，且不得超过3.3V。
- 第7页LED4为3.3V电源指示灯，不受FPGA控制；不要与LED1/LED2混淆。
